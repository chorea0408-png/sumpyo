# 숨표

> 예배 준비는 보이게, 내 시간에는 숨표를.

**🔗 라이브 데모:** https://chorea0408-png.github.io/sumpyo/
(모바일 사파리/크롬에서 열고 "홈 화면에 추가"하면 앱처럼 실행됩니다)

3개의 찬양팀을 병행하는 평신도 인도자가 카톡·메모·구글시트에 흩어진
준비 업무를 **한 화면에서 파악**하고, **지금 해야 할 한 가지**를 놓치지 않게 돕는
개인용 주간 운영 대시보드.

**한 문장** — "Praise Hub가 팀에게 콘티와 악보를 공유하는 서비스라면,
숨표는 세 개의 찬양팀을 병행하는 개인 인도자가 이번 주의 병목과 다음 행동을 파악하는 서비스입니다."

> 📄 **설계 의도·아키텍처·결정 기록 전체는 [`docs/OVERVIEW.md`](docs/OVERVIEW.md)**
> 코드를 고치기 전에 먼저 읽으면 좋습니다 (특히 CSS 캐스케이드·백업 파싱 규칙).

## 실행

```bash
npm install
npm run dev      # http://localhost:5174
npm run build    # 타입체크 + 프로덕션 빌드 (유일한 자동 게이트)
```

## 배포

**`main`에 푸시하면 GitHub Actions가 자동 배포합니다** (`.github/workflows/deploy.yml`).
평소엔 별도 명령이 필요 없습니다. `npm run deploy`는 수동 폴백입니다.

- 호스팅: GitHub Pages (`gh-pages` 브랜치), 저장소 `chorea0408-png/sumpyo`
- 프로덕션 base 경로는 `/sumpyo/` (Vite `base`), 로컬 개발은 `/`
- 배포 직후 검증 시 **서비스워커 캐시 주의** — 재방문 브라우저는 옛 빌드를 계속 서빙합니다

## 화면

하단 탭 3개(기본) + 프로젝트 탭(‘길게 보기’ 모드 ON 시) + 팀 관리 풀페이지.

| 화면 | 역할 |
|---|---|
| **홈** | 가장 먼저 할 일 상위 5건 · 다가오는 마감 · 대기 중인 일 · 지난주 이월 · 주간 현황 · 팀별 진행률 |
| **캘린더** | 월 그리드(기본) / 목록 토글, 예배별 준비팩 진입 |
| **프로젝트** | 수련회·행사 등 장기 프로젝트 + 마일스톤 + 예산·정산문 (조건부 탭) |
| **마이페이지** | 프로필 · 팀 목록 · 준비 통계 · 공지문 문구 · 백업/내보내기 · 설정 |
| **팀 관리** | 기본정보 · 팀원&역할 · 라인업 · 준비팩 구성 · 지난 예배 기록 · 팀원 성장 · 예산 |

## 핵심 동작

- **주간 준비팩 12단계** — 이번 주·다음 주는 항상 자동 보장, 팀별 커스터마이징 가능
- **가장 먼저 할 일** — 마감 + 선행 단계(`STEP_PREREQS`)를 함께 보고 정렬, 막힌 이유를 표시
- **라인업 로테이션 추천** — 역할별로 최근에 안 선 사람 우선, 확정 시 히스토리 기록
- **팀원 성장 통계** — "다은은 싱어 11회, 세컨 0회". 자격은 있는데 0회인 역할을 드러내 로테이션 사각지대를 보여줌
- **답을 기다리는 중** — 남의 응답 대기 항목을 분리. 공유 텍스트엔 절대 포함하지 않음
- **카톡 텍스트 복사 3종** — 주간 현황 · 라인업 공지문 · 프로젝트 정산문
- **localStorage 전용** — 서버·로그인 없음. 백업 JSON export/import로 기기 이동

## 언어 원칙

업무가 밀렸다는 죄책감을 주지 않는다. "지연" 대신 **"확인이 필요해요"**,
게임식 점수 대신 **"27번의 예배를 함께 준비했어요"**. 스트릭은 의도적으로 만들지 않는다.

## 범위 밖

로그인 · 서버 · 팀원 초대 · 실시간 협업 · 악보 뷰어 · AI · 커뮤니티 · 푸시 알림
(악보·음원은 저작권 문제로 외부 링크만 취급)

예산·정산 기능은 있지만 **개인별 잔액이나 미정산 상태는 만들지 않습니다** —
그 순간 계정 시스템이 필요해지고, 개인용 도구라는 전제가 깨지기 때문입니다.

## 부속 도구

```bash
node scripts/backup-to-report.mjs 백업파일.json [출력폴더]
```
마이페이지에서 내려받은 백업 JSON을 `teams` / `members` / `tasks` / `weekly_progress` / `lineup` CSV 5종으로 변환합니다 (앱 번들과 무관한 독립 스크립트, 새 의존성 없음).
